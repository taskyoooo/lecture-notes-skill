# 课堂讲义整理 Skill

把课堂逐字稿整理成可回查、可修订的讲义，生成当讲导图与图表，并检查 PDF 排版。中文优先，可配置教师风格和课程规则。

这是给 AI 编程助手使用的工作流技能，不是独立转写软件，也不保证在缺少 PDF 工具时完成导出。原文、讲授观点、学生发言、整理补充和查证结论需要分清。

## 安装与调用

将 `skills/lecture-notes` 目录复制到支持 SKILL.md 的助手技能目录。Codex 本地安装示例：

```sh
mkdir -p ~/.codex/skills
cp -R skills/lecture-notes ~/.codex/skills/lecture-notes
```

上传自己有权处理的逐字稿，在对话中调用：

> 使用 $lecture-notes，参考上一讲最终稿，整理这次课堂讲义。保留原文定位，补充当讲导图，输出 Markdown、HTML 和带页码的 PDF。

可选：复制 `references/course-profile.example.yaml` 为私有课程配置，并在对话中提供；私有配置保存在仓库外。先审阅教师名、日期、发言人和交付要求，再执行制作。

## 课代表快速上手

第一次只需提供本讲逐字稿。手头已有上一讲最终稿、课程要求或老师批注时，可以一并附上。

> 使用 $lecture-notes 整理本讲笔记，保留几句可核对的老师原话，把概念和案例写具体。附老师送审文案。课堂有明确作业时，再附群通知草稿。

期末可另加一句“接续既有各讲最终稿，整理八讲复习笔记和贯通图”。

每次发布的变化见 [更新日志](CHANGELOG.md)。

## 工作流程

1. 读取最新课堂材料、上一讲定稿和用户修订，明确继承项与本讲变化。
2. 通读全文，建立时间戳或行号覆盖记录，辨别发言归属。
3. 按课堂逻辑组织章节，概念分别说明，深化融入对应段落。
4. 导图表示关系；曲线核对公式、坐标和单位；白板照片与定量数据区别处理。
5. 输出同源的可编辑稿、阅读稿、PDF及私有核查记录。
6. 逐页渲染检查，修改后同步所有受影响版本。

准备来源清单（纯 Python 标准库，本地运行）：

```sh
python3 skills/lecture-notes/scripts/prepare_transcript.py path/to/transcript.md --out path/to/private-work
```

脚本生成 SHA-256、相对行号与时间戳分段，建立覆盖记录模板。之后由人工或助手填写每段处理方式，再运行：

```sh
python3 skills/lecture-notes/scripts/prepare_transcript.py --check path/to/private-work/coverage.json
```

检查脚本核验结构、行号覆盖与填写状态；内容是否准确仍需对照原文、查证并审阅。脚本不联网，不调用模型，不自动发布，也不生成 PDF。排版由所用助手的文档/PDF能力完成；能力不足时应交付已完成文件并说明缺项。

## 输出约定

- 课堂讲义：Markdown、HTML、PDF。
- 当讲知识导图，以及有材料依据的独立图表。
- 私有核查记录：来源、覆盖、发言归属、待核实项和修改记录。
- 本讲确有学习安排时，另做课后提醒；不自行添加提交期限。

默认 A4、小标宋主标题、黑体一级标题、楷体二级标题、仿宋正文、规范编号和中文标点、页脚“当前页/总页数”。字体和工具需由运行环境提供，可用同类字体替代并说明。用户本次要求优先。

## 数据与发布

本仓库仅包含通用技能、提示词、配置示例和辅助脚本，不含真实课程逐字稿、课堂照片、讲义、个人聊天或私有应用接口。处理得到的课程材料归原权利人，不因使用本技能而获得公开传播许可。发布技能与发布课堂材料是不同操作。
